# Security

Please do not publish exploitable vulnerability details in a public issue.
Report them privately to the project maintainer listed in the repository
metadata, including the affected version, environment, reproduction steps, and
impact. Do not send credentials or unrelated personal data.

Pixeldart performs no runtime network or filesystem access. Browser hosts still
own URL loading, permission policy, and content validation; report issues in
those host layers to the owning application as well.

There is no guaranteed response-time or supported-release commitment yet. The
project will document one before any public package release.
